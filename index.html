Политика конфиденциальности

Обновлено: 5 октября 2025 г.

1. Общие положения

Мобильное приложение «Голосовой калькулятор» предназначено для голосовых вычислений. Данные обрабатываются локально.

2. Сбор и использование данных

  • Мы не собираем персональные данные.
  • Голос обрабатывается локально (или через стандартные API устройства) и не сохраняется нами.

3. Разрешения

Требуется доступ к микрофону для распознавания речи.

4. Хранение

История хранится только на вашем устройстве. Вы можете очистить её в любой момент.
